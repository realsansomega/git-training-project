\# Team Policies



\## Meetings



The team will meet once a week, either in person or online and extra meetings can be scheduled when needed. Everyone should let the team know ahead of time if they cannot attend.



\## Work Assignment



Tasks will be divided based on each member's skills and workload. Each member will be responsible for finishing their assigned tasks by an agreed deadline.



\## Team Roles



Team members can take roles such as project coordinator, programmer, tester, and documentation writer. Roles can change depending on the project and each member's workload.



\## Tools



The team will use GitHub to store code and track changes. The team will use a shared chat or group message to communicate and coordinate work. Project files and instructions will be kept in the repository.



\## Meeting Expectations



Everyone should communicate regularly, complete assigned work on time, and ask for help when needed. If someone is falling behind, the team should discuss the problem and agree on a plan to get back on track.



\## Deliverables



The team will agree on deadlines for each deliverable. Work should be reviewed by at least one other team member before it is submitted. The team will keep the latest approved files in the shared repository and make sure submissions are completed on time.
